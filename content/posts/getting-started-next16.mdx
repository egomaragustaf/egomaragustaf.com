## Why Next.js 16 matters

Next.js 16 makes Turbopack the default bundler and fully removes synchronous access to request-specific data like `params` and `searchParams`. Everything is a Promise now.

### Async params

In a dynamic route page:

```tsx
export default async function Page({
  params,
}: {
  params: Promise<{ slug: string }>;
}) {
  const { slug } = await params;
  // ...
}
```

It takes some getting used to, but it makes the data flow honest — you can never accidentally read a request value during render.
